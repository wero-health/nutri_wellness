# Nutri Wellness

A premium, modern Next.js web application for **Nutri Wellness** — Root-Cause Functional Medicine & Clinical Nutrition led by Dr. Dasari Anusha in Jubilee Hills, Hyderabad.

## Key Features & Clinical Framework
- **Cinematic Hero Carousel**: Dynamic multi-panel wellness hero showcasing high-resolution clinic facilities.
- **The Functional Medicine Tree of Life**: Root-cause diagnostic tree illustrating downstream clinical symptoms vs. core clinical imbalances.
- **Systems Biology Matrix**: Interactive console navigating gut-brain axis, hormone synthesis, metabolic health, and detoxification pathways.
- **Essentials Bento Grid**: Dynamic biomarkers visualizing cellular micronutrients, genomics, and microbiome metrics.
- **Interactive Multi-Step Intake Form**: Comprehensive patient consultation booking workflow.
- **Evidence-Based Health Guides**: Research articles and clinical insights on functional medicine and longevity.

## Tech Stack
- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4, Lucide React icons
- **Animations**: Framer Motion
- **Language**: TypeScript

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Production Build

To test and compile a production bundle:
```bash
npm run build
```
